## 📊 Criterios de Evaluación

| # | Criterio Técnico / Pedagógico | Cumple (SÍ/NO) | Observaciones del Instructor |
| :-: | :--- | :-: | :--- |
| **1** | **Configuración de Autoría:** Los commits reflejan el nombre real y correo del aprendiz (`git config`). | | |
| **2** | **Uso de Ramas (`Branches`):** El trabajo del perfil fue desarrollado en una rama independiente (`perfil/nombre-apellido`) y no directamente sobre `main`. | | |
| **3** | **Mensajes de Commit Estandarizados:** Los commits utilizan mensajes descriptivos y siguen convenciones (`feat:`, `fix:`, `docs:`, etc.). | | |
| **4** | **Estructura del Perfil JSON:** El archivo `perfiles/nombre-apellido.json` está correctamente estructurado, sin errores de sintaxis JSON, y registrado en el dataset. | | |
| **5** | **Funcionamiento Visual Local:** La tarjeta del aprendiz se renderiza correctamente en `index.html` con todos sus datos, habilidades y redes. | | |
| **6** | **Repositorio Remoto en GitHub:** El proyecto está publicado en la cuenta personal de GitHub del aprendiz con historial completo de commits. | | |
| **7** | **Despliegue en GitHub Pages:** La aplicación se encuentra publicada y navegable a través de su URL pública en GitHub Pages. | | |
| **8** | **Documentación y Entrega:** El aprendiz entrega los enlaces solicitados en los tiempos y canales estipulados. | | |
